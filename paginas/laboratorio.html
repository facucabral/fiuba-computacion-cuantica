Laboratorio de circuitos

Armá un circuito de hasta 3 qubits y recorrelo columna por columna. Muestra el estado en notación de Dirac, como lo escribirías en el parcial, y la medición con proyectores.

Cómo se usa

  1. Elegí una herramienta de la paleta (H, X, CNOT…) y tocá una celda del circuito. Para la CNOT tocá primero el control y después el objetivo, en la misma columna.
  2. Cambiá el estado inicial de cada qubit con los selectores ($|0\rangle$, $|1\rangle$, $|+\rangle$, $|-\rangle$).
  3. Recorré los pasos con los botones o tocando una compuerta: la columna resaltada es la que se acaba de aplicar.
  4. Medí todo el sistema o un solo qubit: aparecen el proyector $\hat P$, la probabilidad y el estado después de medir, ya normalizado.
Para verificar, no para reemplazar

Resolvé el ejercicio a mano y usá el laboratorio para revisar el resultado. En el parcial cuenta el desarrollo: estados intermedios con nombre ($\Psi_0, \Psi_1, \dots$), el algoritmo escrito y el proyector.

Circuitos para cargar
