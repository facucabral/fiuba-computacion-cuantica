Sistemas de qubits

Para describir varios qubits juntos se usa el producto tensorial. Con $n$ qubits el vector de estado tiene $2^n$ componentes.

Bajada a tierra

Juntar qubits multiplica en lugar de sumar: 1 qubit tiene 2 casilleros, 2 qubits tienen 4 ($|00\rangle, |01\rangle, |10\rangle, |11\rangle$), 3 qubits tienen 8. El producto tensorial es “cada uno con cada uno”, como armar todas las combinaciones posibles entre dos menús. Por eso con $n$ qubits hay $2^n$ números en juego.

Intuición inspirada en El Qubit de Newton · “Entrelazamiento cuántico”
qubit 1$\htmlClass{q-cambio}{\alpha}|0\rangle + \beta|1\rangle$
⊗
qubit 2$\gamma|0\rangle + \delta|1\rangle$

Cada qubit tiene sus dos coeficientes. Queremos un solo vector que describa a los dos.

$$\htmlClass{q-cambio}{\alpha}|0\rangle\otimes(\gamma|0\rangle + \delta|1\rangle) = \alpha\gamma|00\rangle + \alpha\delta|01\rangle$$

Distributiva: $\alpha|0\rangle$ multiplica a cada término del segundo qubit. Los kets se pegan: $|0\rangle\otimes|1\rangle = |01\rangle$.

$$\htmlClass{q-cambio}{\beta}|1\rangle\otimes(\gamma|0\rangle + \delta|1\rangle) = \beta\gamma|10\rangle + \beta\delta|11\rangle$$

Lo mismo con $\beta|1\rangle$. El primer dígito de cada ket siempre es el del qubit 1.

$$|\psi\rangle = \alpha\gamma|00\rangle + \alpha\delta|01\rangle + \beta\gamma|10\rangle + \beta\delta|11\rangle = \begin{pmatrix}\alpha\gamma\\ \alpha\delta\\ \beta\gamma\\ \beta\delta\end{pmatrix}$$

Cuatro amplitudes, en orden binario 00, 01, 10, 11. Si existe esta factorización, el estado es separable; si no existe, está entrelazado.

El producto tensorial

Las compuertas de dos qubits, como la CNOT, actúan sobre un vector que describe a ambos. Ese vector se arma con el producto tensorial $\otimes$: cada componente del primero multiplica al segundo vector entero.

$$\begin{pmatrix}\alpha_1\\\beta_1\end{pmatrix}\otimes\begin{pmatrix}\alpha_2\\\beta_2\end{pmatrix} = \begin{pmatrix}\alpha_1\alpha_2\\\alpha_1\beta_2\\\beta_1\alpha_2\\\beta_1\beta_2\end{pmatrix} = \alpha_1\alpha_2|00\rangle + \alpha_1\beta_2|01\rangle + \beta_1\alpha_2|10\rangle + \beta_1\beta_2|11\rangle$$

Se abrevia $|a\rangle\otimes|b\rangle = |a\rangle|b\rangle = |ab\rangle$. En $|q_1q_2\rangle$, el primer dígito es el qubit 1, la línea de arriba del circuito.

La base de 2 y 3 qubits

$$|00\rangle = \begin{pmatrix}1\\0\\0\\0\end{pmatrix},\quad |01\rangle = \begin{pmatrix}0\\1\\0\\0\end{pmatrix},\quad |10\rangle = \begin{pmatrix}0\\0\\1\\0\end{pmatrix},\quad |11\rangle = \begin{pmatrix}0\\0\\0\\1\end{pmatrix}$$

Con 3 qubits: $|000\rangle, |001\rangle, \dots, |111\rangle$, ocho vectores. El índice de cada uno es el número binario de la etiqueta: $|101\rangle$ es el sexto (índice 5).

Propiedades que se usan en las cuentas

  • Distributiva: $(a|0\rangle + b|1\rangle)\otimes|0\rangle = a|00\rangle + b|10\rangle$.
  • Escalares afuera: $(a|\psi\rangle)\otimes|\varphi\rangle = a\,(|\psi\rangle\otimes|\varphi\rangle)$.
  • Producto interno por partes: $\langle ab|cd\rangle = \langle a|c\rangle\langle b|d\rangle$. Por ejemplo, $\langle 01|01\rangle = 1$ y $\langle 01|11\rangle = \langle0|1\rangle\langle1|1\rangle = 0$.
  • Operadores por partes: $(A\otimes B)(|a\rangle\otimes|b\rangle) = A|a\rangle\otimes B|b\rangle$. Así se aplica, por ejemplo, $H\otimes X$.
Compuerta sobre un solo qubit

Si una compuerta actúa solo sobre el qubit 1, en el sistema completo es $U\otimes I$; si actúa sobre el 2, $I\otimes U$. Eso se escribe en el “algoritmo”: $(H\otimes I)$, $(I\otimes Z)$…

Medir un solo qubit

Es lo que piden los ejercicios 1, 2 y 5. El proyector sobre el qubit medido se combina con la identidad en los demás. Para medir el qubit 1 y obtener 0:

$$\hat P^{(1)}_0 = |0\rangle\langle 0|\otimes I, \qquad p_1(0) = \langle\Psi|\hat P^{(1)}_0|\Psi\rangle, \qquad |\tilde\Psi\rangle = \frac{\hat P^{(1)}_0|\Psi\rangle}{\sqrt{p_1(0)}}$$

En la práctica: te quedás con los términos donde ese qubit vale lo medido, sumás los módulos al cuadrado de sus coeficientes (esa es la probabilidad) y normalizás lo que quedó.

Ejemplo resuelto (guía 4, ejercicio 4)

$|\Psi\rangle = \tfrac12(|00\rangle - |01\rangle + |10\rangle - |11\rangle)$.

  1. ¿Producto o entrelazado? Factorizá: $\tfrac12(|0\rangle + |1\rangle)\otimes(|0\rangle - |1\rangle) = |+\rangle\otimes|-\rangle$. Es un estado producto (separable).
  2. Probabilidades de cada qubit. Términos con $q_1 = 0$: $|00\rangle$ y $-|01\rangle$, entonces $p_1(0) = \tfrac14 + \tfrac14 = \tfrac12$ y $p_1(1) = \tfrac12$. Igual para $q_2$: $p_2(0) = p_2(1) = \tfrac12$.
  3. Si en $q_1$ se mide 0. $\hat P^{(1)}_0|\Psi\rangle = \tfrac12(|00\rangle - |01\rangle)$; dividiendo por $\sqrt{1/2}$: $|\tilde\Psi\rangle = \tfrac{1}{\sqrt2}(|00\rangle - |01\rangle) = |0\rangle|-\rangle$.
  4. ¿Afecta a la medición de $q_2$? No: antes y después $q_2$ está en $|-\rangle$ y da 0 o 1 con 50 %. En un estado producto, medir un qubit no cambia lo que se puede predecir del otro.
  5. Probabilidad de $|11\rangle$. $p(11) = |\langle 11|\Psi\rangle|^2 = \left|-\tfrac12\right|^2 = \tfrac14$, y el estado posterior es $|11\rangle$.

¿Separable o entrelazado?

Un estado de dos qubits es separable (producto) si se puede escribir como $|\psi_1\rangle\otimes|\psi_2\rangle$. Si no, está entrelazado. Para dos qubits hay un test rápido con los coeficientes de $c_{00}|00\rangle + c_{01}|01\rangle + c_{10}|10\rangle + c_{11}|11\rangle$:

$$\text{separable} \iff c_{00}\,c_{11} - c_{01}\,c_{10} = 0$$

Se deduce de igualar $c_{00} = \alpha_1\alpha_2$, $c_{01} = \alpha_1\beta_2$, $c_{10} = \beta_1\alpha_2$, $c_{11} = \beta_1\beta_2$: si existe la factorización, el “determinante” se anula.

Separable

$\tfrac{1}{\sqrt2}(|00\rangle + |01\rangle)$: $c_{00}c_{11} - c_{01}c_{10} = 0 - 0 = 0$. Es $|0\rangle|+\rangle$.

Entrelazado

$\tfrac{1}{\sqrt2}(|00\rangle + |11\rangle)$: $\tfrac12 - 0 = \tfrac12 \ne 0$. Es el par de Bell $|\beta_{00}\rangle$.

Recuperatorio 2026, ej. 5c

Pidieron decir si $\tfrac{i}{\sqrt2}(|11\rangle - |10\rangle)$ está entrelazado. No: $c_{00}c_{11} - c_{01}c_{10} = 0\cdot\tfrac{i}{\sqrt2} - 0\cdot\left(-\tfrac{i}{\sqrt2}\right) = 0$. Factorizado: $i\,|1\rangle\otimes\tfrac{1}{\sqrt2}(|1\rangle - |0\rangle) = -i\,|1\rangle|-\rangle$. Dos términos no significan entrelazamiento.
